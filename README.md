# Калькулятор акций — Академия «Инвестиции просто»

Веб-калькулятор для оценки российских акций по 10-балльной шкале со светофором. Сделан в одном HTML-файле, открывается в браузере или в Telegram Mini App.

## Что умеет

- Поиск любой российской акции через MOEX ISS API (по тикеру или названию).
- Автоматическая подтяжка цены, капитализации и сектора с MOEX.
- Скоринг по 9 фундаментальным метрикам с разделением на зоны (зелёная/жёлтая/красная).
- 5 качественных факторов (сектор, стратегия, корпуправление, дивполитика, чистая история).
- Особый режим для банков — Debt/Equity исключается из расчёта.
- Сравнение нескольких акций с автосортировкой по баллу.
- Экспорт результата в Excel.
- Access gate через Telegram + Supabase для учеников академии (включается параметром `?access=academy`).

## Как пользоваться

1. Открыть страницу `index.html` в браузере (или через бот академии).
2. Найти акцию через поле поиска — ввести тикер (например, `SBER`) или название.
3. Если компания — банк, поставить чекбокс «Это банк или финансовая компания».
4. Заполнить мультипликаторы и финпоказатели из отчётности эмитента или smart-lab.ru.
5. Отметить качественные факторы.
6. Перейти на вкладку «Скоринг» — посмотреть итоговый балл и разбор по блокам.
7. По желанию: скачать в Excel или добавить в сравнение.

## Пороги скоринга

| Метрика | Зелёный | Жёлтый | Красный |
|---|---|---|---|
| P/E | ≤ 5 | 5 – 10 | > 10 |
| P/B | ≤ 1 | 1 – 2 | > 2 |
| P/S | ≤ 1 | 1 – 2 | > 2 |
| ROE | ≥ 15% | 8 – 15% | < 8% |
| ROA | ≥ 7% | 3 – 7% | < 3% |
| Debt/Equity | ≤ 0,5 | 0,5 – 1,5 | > 1,5 |
| Дивдоходность | ≥ 8% | 5 – 8% | < 5% |
| Рост выручки YoY | ≥ 15% | 5 – 15% | < 5% |
| Рост прибыли YoY | ≥ 15% | 0 – 15% | < 0% |

Качественные факторы — каждое «да» добавляет 0,5 балла к итогу (максимум 2,5).

## Итоговый вердикт

- **8 – 10 баллов** → зелёный, «достойно изучения дальше»
- **5 – 7,9 балла** → жёлтый, «спорная история»
- **0 – 4,9 балла** → красный, «лучше пропустить»

## Технологии

- Чистый HTML / CSS / JS, без сборки и фреймворков.
- [MOEX ISS API](https://iss.moex.com/iss/reference/) — поиск и подтяжка котировок.
- [SheetJS](https://sheetjs.com/) — экспорт в Excel.
- Supabase Edge Function — проверка доступа учеников академии.
- (Roadmap) Supabase + T-Invest API `GetAssetFundamentals` — автоподтяжка фундаменталки.
